# User Excel data 公開サンプル

`user_data.xlsx` は、常時読み込みの `User Excel data` ワークフローを確認するために
EnvGeo-Seawaterへ同梱する、データ行0件の公開サンプルブックです。研究者の測定データは
含みません。外部データパスを指定しない場合、アプリは起動時にこのブックを読み込みます。

英語版は `README.md` を参照してください。

## 研究者自身のデータを使う方法

次のいずれかを選べます。

1. ローカル利用のために `local_data/user_data.xlsx` へデータを入力する。
2. `ENVGEO_LOCAL_USER_DATA_PATH` で、CSV、XLSX、XLSの別ファイルを指定する。

```bash
ENVGEO_LOCAL_USER_DATA_PATH=/absolute/path/to/user_data.xlsx streamlit run home.py
```

どちらの方法でも、共通ローダーはブラウザアップロードと同じ列名標準化・品質検査を適用し、
データ行に `User Excel data` のDataset名を付けて、選択中の参照データへ結合します。
ブラウザでアップロードする `Uploaded data` はセッション限定の別データセットであり、
両方を選択した場合は両方を利用します。

## ローカル利用と公開時の注意

`user_data.xlsx` は公開サンプルとしてGit管理します。ローカル解析のために編集できますが、
commitや公開クローンへの同期前には、データ行0件の公開サンプルへ戻してください。
研究者自身の測定データ、未公表データ、制限付きデータ、再配布できないデータはcommitしません。

同梱ブックまたは外部指定した表を変更した後は、Streamlitを再起動するかデータキャッシュを
クリアしてから再読み込みしてください。

## データクリーニングとテスト

ローダーは、数値変換の前に通常空白、ノーブレークスペース、狭いノーブレークスペース、
全角空白を除去します。それでも数値として解釈できない値は欠損とし、通常の品質検査で扱います。

自動テストでは `ENVGEO_DISABLE_LOCAL_USER_DATA=1` を設定するため、テスト結果は
同梱ブックや外部指定ファイルの内容に依存しません。
