# Isotope & Hydrographic Mapping

## What This Page Does

This page maps isotope and hydrographic parameters such as d18O, dD, d-excess, salinity, and temperature.

## Basic Workflow

1. Select a dataset.
2. Apply sidebar filters.
3. Choose the mapped parameter.
4. Choose map type.
5. Adjust map display settings.
6. Download the map if needed.

## Main Controls

- **Mapped parameter**
- **Map type**
- **Map center**
- **Colormap**
- **Map longitude / latitude range**
- **Colorbar range**
- **Colorbar thickness / length / font size**
- **Map controls / Map style**

## Outputs

- Scatter map
- Contour-style map
- Sampling location map
- Downloadable map images
- Filtered dataset table

## Notes And Limitations

- Contour-style maps depend on data density and interpolation behavior.
- Map display settings are independent from Data filtering settings.
