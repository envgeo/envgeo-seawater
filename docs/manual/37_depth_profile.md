# Depth Profile

## What This Page Does

This page plots vertical profiles of selected seawater parameters against water depth.

## Basic Workflow

1. Select a dataset.
2. Choose a profile parameter.
3. Choose whether to show background data.
4. Apply sidebar filters.
5. Adjust depth range, axis range, figure size, fonts, and tick counts.
6. Download the figure if needed.

## Main Controls

- **Show background data**
- **Profile parameter**
- **Depth range**
- **Axis scale**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**
- **Map controls / Map style**

## Outputs

- Depth profile plot
- Sampling location map
- Downloadable PNG figure
- Filtered dataset table

## Notes And Limitations

- dD and d-excess may have many missing values.
- Gap rows are inserted to avoid connecting unrelated observation groups.
- Long filter-condition titles are wrapped in downloaded images.
