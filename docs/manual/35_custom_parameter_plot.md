# Custom Parameter Plot beta

## What This Page Does

This beta page creates flexible 2D plots from selected numeric parameters.

## Basic Workflow

1. Select a dataset.
2. Apply sidebar filters.
3. Choose X and Y parameters.
4. Choose color and size parameters if needed.
5. Adjust axis ranges and figure appearance.
6. Download the figure if needed.

## Main Controls

- **X axis**
- **Y axis**
- **Color parameter**
- **Size parameter**
- **Show background data**
- **Show legend**
- **Regression line**
- **Axis ranges**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**

## Outputs

- Custom 2D scatter plot
- Optional colorbar and size scaling
- Optional regression line
- Downloadable PNG figure
- Selected dataset table

## Notes And Limitations

- This page is experimental.
- It is useful for quick exploration of parameter relationships such as dD vs d18O, colored by depth.
