# 4D Visualizer

## What This Page Does

This page visualizes seawater data using 3D/4D scatter plots, including map-depth views.

## Basic Workflow

1. Select a dataset.
2. Apply sidebar filters.
3. Choose a 4D view.
4. Adjust map-depth region and figure settings.
5. Adjust colorbar range.
6. Inspect the 4D plot and sampling-location map.

## Main Controls

- **4D view**
- **Custom view type**
- **Map center for map-depth views**
- **Map-depth region preset**
- **Colormap**
- **Colorbar range**
- **Map controls / Map style**

## Outputs

- Standard Fig.1-Fig.6 style 4D views
- Custom 4D view beta
- Sampling location map
- Selected-data table

## Notes And Limitations

- This page can be slow for large global selections.
- Map-depth views use geographic scaling and coastline overlays.
- Custom 4D view beta is experimental and may change.
