# GitHub Pages image copies / GitHub Pages用画像コピー

`../../../images/` is the canonical source of the public example figures used
by the repository README. Files in this directory are intentionally copied for
the GitHub Pages site, whose simple branch-and-`/docs` deployment cannot serve
assets from the repository root.

Do not edit these copies independently. When an example figure is added or
replaced, update the canonical `images/` file first, copy the same file here,
and verify both the README and the Pages site after publishing. Do not delete
or move either copy until the published site has been checked.

`../../../images/` は、リポジトリREADMEで使う公開例図の正規の元画像です。このディレクトリのファイルは、
repository rootの画像をそのまま配信できない、単純なbranch-and-`/docs`方式のGitHub Pagesのために意図して
コピーしています。

このコピーだけを個別に編集しません。例図を追加・差替えするときは、先に正規の`images/`を更新し、同じファイルを
ここへコピーして、公開後にREADMEとPages siteの両方を確認します。公開サイトを確認するまでは、どちらのコピーも
削除・移動しません。
