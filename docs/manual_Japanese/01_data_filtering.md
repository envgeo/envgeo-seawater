# Data filtering

## この機能でできること

多くの EnvGeo-Seawater ページでは、共通のサイドバーフィルタを使って、図や表に表示するデータを選択します。

## 基本操作

1. データセットや transect を選択する。
2. 年・月を選択する。
3. 必要に応じて Area filter preset を選ぶ。
4. 経度・緯度を微調整する。
5. 水深、塩分、d18O、水温の範囲を調整する。
6. **Apply settings** を押して図へ反映する。

## Uploaded data

対応ページでは、ブラウザからアップロードした行が **Select sub-dataset** 内の
**Uploaded data** として表示されます。これだけを選べばアップロードデータだけを
描画でき、参照データと同時に選べば同じフィルターを両方へ適用します。必要な箇所では
アップロードデータの件数も表示します。アップロード点は最前面に描画されます。

Vertical Sectionでは、選択されたアップロード行を参照データとともに対応可能な断面計算へ
使います。一方、計算上アップロード点を意図的に除く必要があるページでは専用オーバーレイ
として扱うため、各ページの説明を確認してください。

## 常時読み込みのUser Excel data

ローカルで繰り返し解析する場合は、`local_data/user_data.xlsx` をアプリ起動時に
読み込み、**User Excel data** というデータセット名を付けます。日本海、日本周辺、
全球のどの参照データを選択した場合でも結合されるため、ブラウザから毎回
アップロードする必要はありません。別のCSV/XLSX/XLSを使う場合は
`ENVGEO_LOCAL_USER_DATA_PATH` で指定します。ローカルデータはGit管理対象外です。

**User Excel data** とブラウザの **Uploaded data** は別のデータセットです。
両方を選択した場合は両方を使い、ブラウザアップロードによって常時読み込み表を
上書きしません。

他の表計算ソフトから数値をコピーすると、ノーブレークスペースや全角空白などの
見えない空白が混入することがあります。共通ローダーはこれらを除去してから数値化します。
それでも数値として解釈できない値は欠損値とし、通常の品質検査の対象にします。

## 主な設定

- **Area filter preset**  
  よく使う海域プリセットから、経度・緯度の初期範囲を設定します。

- **Longitude / Latitude**  
  地理範囲を手動で調整します。

- **Year / Month**  
  採水時期を絞り込みます。

- **Water Depth, Salinity, d18O, Temperature**  
  水文・同位体条件で絞り込みます。

## 出力

- Filtered dataset
- Details and statistics of filtered data
- 抽出データ概要CSV
- 品質フラグ基準

## 注意点

- フィルタ条件を変更しただけでは図は更新されません。**Apply settings** を押してください。
- Area preset は初期範囲を設定するためのもので、選択後もスライダーで微調整できます。
- 欠損値を含む行は、条件によっては残す設計になっています。
- **Filtered dataset** にはサイドバーのフィルターを通過した全行を表示します。
  一方、例えば Salinity–d18O 図で必須軸の値が欠けている場合は描画されないため、
  プロット件数が少なくなることがあります。その除外件数はページ上で別に表示します。
