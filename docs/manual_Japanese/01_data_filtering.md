# データの絞り込み

## この機能でできること

多くの EnvGeo-Seawater ページでは、共通のサイドバーフィルタを使って、図や表に表示するデータを選択します。

## 基本操作

1. データセットと、表示される場合はtransectを選択します。
2. 年・月を選択する。
3. 必要に応じて Area filter preset を選ぶ。
4. 経度・緯度を微調整する。
5. 必要に応じて、水深、塩分、d18O、水温の範囲を調整します。
6. **Apply settings**を選び、図へ反映します。

## Uploaded data

ブラウザからのアップロードは、**User Data Check & Quick Visualizer**、salinity--d18O、mapping、T--S、custom-parameter、depth-profile、vertical-sectionの各ページで使えます。これらのページでは、アップロードした行がデータセット選択欄に**Uploaded data**として表示されます。これだけを選べばアップロードデータだけを描画でき、参照データと同時に選べば同じフィルターを両方へ適用します。対応する重ね描きでは、アップロード点を前面に表示します。

2Dplusと3D/4Dでは、現時点でブラウザからのアップロードには対応していません。描画や計算上の制約は、各ページの説明を確認してください。

## 常時読み込みのUser Excel data

ゼロ値の公開サンプル`local_data/user_data.xlsx`は、既定の任意ローカル表です。サンプルには観測値が入っていないため、データ選択欄に**User Excel data**が表示されるのは、設定したローカル表に実データ行がある場合だけです。

常時使う個人データは、アプリ起動前に`ENVGEO_LOCAL_USER_DATA_PATH`でrepository外のCSV、XLSX、XLSファイルを指定します。個人データをrepositoryやアプリフォルダへ入れないでください。必要に応じて`ENVGEO_DISABLE_LOCAL_USER_DATA`で任意ローカル表の読み込みを停止できます。

**User Excel data** とブラウザの **Uploaded data** は別のデータセットです。
両方を選択した場合は両方を使い、ブラウザアップロードによって常時読み込み表を
上書きしません。

他の表計算ソフトから数値をコピーすると、ノーブレークスペースや全角空白などの
見えない空白が混入することがあります。共通ローダーはこれらを除去してから数値化します。
それでも数値として解釈できない値は欠損値とし、通常の品質検査の対象にします。

## 主な設定

- **Area filter preset**  
  よく使う海域プリセットから、経度・緯度の初期範囲を設定します。

- **Longitude / Latitude**  
  地理範囲を手動で調整します。

- **Year / Month**  
  採水時期を絞り込みます。

- **Water Depth, Salinity, d18O, Temperature**  
  水文・同位体条件で絞り込みます。

## 出力

- Filtered dataset
- Details and statistics of filtered data
- 抽出データ概要CSV
- ページに用意されている品質情報と書き出し操作

## 注意点

- フィルタ条件を変更しただけでは図は更新されません。**Apply settings** を押してください。
- Area preset は初期範囲を設定するためのもので、選択後もスライダーで微調整できます。
- データの区切りを保つためのgap rowを意図せず除外しないよう、一部のフィルターでは欠損値を含む行を残す設計になっています。
- **Filtered dataset** にはサイドバーのフィルターを通過した全行を表示します。
  一方、例えば Salinity–d18O 図で必須軸の値が欠けている場合は描画されないため、
  プロット件数が少なくなることがあります。その除外件数はページ上で別に表示します。
