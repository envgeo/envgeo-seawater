# Vertical Section Visualizer beta

## このページでできること

選択した測線に沿った鉛直断面図を試験的に作成する beta ページです。

## 基本操作

1. 断面の測線を選択または設定する。
2. データと bathymetry source を選ぶ。
3. 補間や表示設定を調整する。
4. 鉛直断面図を確認する。
5. 必要に応じて設定を再調整する。

## 主な設定

- Section control panel
- Section path settings
- Bathymetry source
- Uploaded bathymetry file
- Interpolation and plotting settings

## 出力

- 鉛直断面図
- 断面位置図または補助図
- 利用可能な場合は断面選択データ表

## 注意点

- このページはまだ beta です。
- 鉛直断面補間は、科学的にも計算的にも慎重な扱いが必要です。
- 最終的な解析図として使う前に、補間方法や表示条件の検証が必要です。
