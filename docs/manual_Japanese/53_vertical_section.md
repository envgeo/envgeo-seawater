# 鉛直断面ビジュアライザー（beta）

## このページでできること

選択した軸または A–B 測線に沿って補間した鉛直断面図を作成する試験的なページです。
探索的な確認を目的とし、独立した検証なしに最終的な科学的解釈へ用いることは想定していません。

## 基本操作

1. 参照データを選択し、共通のフィルター条件を設定する。
2. **Axis-based** モードを選ぶか、**A-B section** を選んで端点を入力する、または
   選択地図で線を描く。
3. corridor の半幅を設定する。A-B モードでは、この範囲内の観測点だけを測線へ投影します。
4. 対象パラメーター、海底地形データ源、表示設定を選ぶ。
5. カラー・等値線の断面図、Section Map、断面データ表を確認する。
6. 補間に使う行が多すぎる場合は、フィルターまたは corridor を絞る。

## アップロードデータを含む断面計算

経度、緯度、水深、選択中の対象パラメーターを含むデータをアップロードするか、同じセッションの共有データを再利用できます。A-B モードでは現在の corridor 内のアップロード点を測線へ投影し、Axis-based モードでは参照データと同じ軸座標・距離原点を使います。共通の Data filtering で **Uploaded data** を選択すると、有効なアップロード行は選択中の参照データとローカル統合され、断面投影、補間、等値線、観測最深値による海底フォールバックに使われます。選択を解除すると、計算・表示の両方から外れます。アップロード点は選択地図、断面図、Section Map の最前面に別マーカーで表示されます。選択中の対象パラメーターについて、有効値・欠損／不正値の件数も確認できます。

## 主な設定

- 共通のユーザーデータアップロード・列対応・マーカー設定
- 他の可視化ページと共通のData filteringフォーム
- **Section mode** — Axis-based（`Longitude_degE`、`Latitude_degN`、`Distance_km`）または
  A-B section。
- **A-B endpoints / Draw on map** — 端点の手入力は常に利用できます。地図への描画には
  `folium` と `streamlit-folium` が必要で、**Coastline (offline)** モードでは使えません。
- **Half-width of section corridor** と **Show section corridor**。
- **Bathymetry source** — 内蔵 GEBCO、CSV/Excel でアップロードした地形表、または観測最深値。
  GEBCO は A-B section にだけ使用し、断面を取得できないときは理由を示してフォールバックします。
- **Resolution**、**Smoothing (visual only)**、補間に使用する最大行数。共有・Cloud 環境の
  負荷を抑えるため、アプリ内部にも上限があります。
- 対象パラメーターの範囲、カラーマップ、水平カラーバーの設定。

## 出力

- カラー表示と等値線表示の断面図
- 測線、corridor、使用観測点を示す Section Map
- 断面計算に使用した行を展開表示するデータ表

## 注意点

- このページは beta です。鉛直断面の補間は科学的にも計算的にも慎重な扱いが必要です。
  最終的な解析図として使う前に、補間方法と表示条件を検証してください。
- 補間は安全なフォールバック順（cubic、linear、必要時の nearest neighbour）で実行します。
  nearest neighbour の外挿だけで埋められたセルは低信頼領域として見分けられますが、観測値ではありません。
- Smoothing は補間済みグリッドの見た目だけを変えます。観測値を追加したり、物理的な連続性を
  示すものではありません。
- 海底地形は表示の制約条件であり、地形解析ではありません。選択したデータ源から有効な断面が
  得られない場合は、観測最深値へフォールバックします。
- 日付変更線（180°/−180°）を直接またぐ測線は、検証されていない局所平面近似を使います。
  この場合の出力は概略的な視覚参照としてのみ扱ってください。
- ブラウザからのアップロードはセッション内だけで使用され、参照データや永続的な
  **User Excel data** を変更するものではありません。
