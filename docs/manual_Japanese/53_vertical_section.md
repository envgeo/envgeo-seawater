# Vertical Section Visualizer beta

## このページでできること

選択した測線に沿った鉛直断面図を試験的に作成する beta ページです。

## 基本操作

1. 断面の測線を選択または設定する。
2. データと bathymetry source を選ぶ。
3. 補間や表示設定を調整する。
4. 鉛直断面図を確認する。
5. 必要に応じて設定を再調整する。

## アップロードデータを含む断面計算

経度、緯度、水深、選択中の対象パラメーターを含むデータをアップロードするか、同じセッションの共有データを再利用できます。A-Bモードでは現在のcorridor内のアップロード点を測線へ投影し、Axis-basedモードでは参照データと同じ軸座標・距離原点を使います。Data filteringで**Uploaded data**を選択した場合、有効なアップロード行は選択中の参照データとローカル統合され、断面投影、補間、等値線、観測最深値による海底フォールバックに使われます。選択を解除すると、計算・表示の両方から外れます。アップロード点はA-B選択地図、断面図、Section Mapの最前面に別マーカーで表示されます。選択中target parameterについて、有効値・欠損／不正値の件数も確認できます。

## 主な設定

- 共通のユーザーデータアップロード・列対応・マーカー設定
- 他の可視化ページと共通のData filteringフォーム
- Section path settings
- Bathymetry source
- Uploaded bathymetry file
- 補間・描画設定（カラーマップ、水平カラーバーの長さ・太さ・文字サイズ・目盛数を含む）

## 出力

- 鉛直断面図
- 断面位置図または補助図
- 利用可能な場合は断面選択データ表

## 注意点

- このページはまだ beta です。
- 鉛直断面補間は、科学的にも計算的にも慎重な扱いが必要です。
- 最終的な解析図として使う前に、補間方法や表示条件の検証が必要です。
