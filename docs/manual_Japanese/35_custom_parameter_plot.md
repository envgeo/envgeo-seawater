# Custom Parameter Plot beta

## このページでできること

任意の数値パラメーターを選んで、柔軟な2D散布図を作成する beta ページです。

## 基本操作

1. データセットを選択する。
2. Data filtering を適用する。
3. X軸とY軸のパラメーターを選ぶ。
4. 必要に応じて色やサイズのパラメーターを選ぶ。
5. 軸範囲や図の見た目を調整する。
6. 必要に応じて図をダウンロードする。

## 主な設定

- **X axis**
- **Y axis**
- **Color parameter**
- **Size parameter**
- **Show background data**
- **Show legend**
- **Regression line**
- **Axis ranges**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**

## 出力

- 任意パラメーターの2D散布図
- 任意のカラーバー・サイズ表現
- 任意の回帰線
- ダウンロード可能な PNG 図
- 選択データ表

## 注意点

- このページは試験的機能です。
- dD vs d18O を水深で色分けするなど、関係性の探索に向いています。
