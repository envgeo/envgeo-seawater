# 任意パラメーター図

## このページでできること

任意の数値パラメーターを選び、柔軟な 2D 散布図を作成するページです。
フィルタ後の参照データに、ブラウザから任意にアップロードしたデータを重ねて表示できます。

## 基本操作

1. 参照データを選択し、サイドバーで条件を設定する。
2. 必要に応じて CSV、XLSX、または XLS をアップロードする。数値列は X 軸、Y 軸、色、
   サイズの候補として利用できます。
3. X 軸と Y 軸を選び、必要に応じて **Color by** と **Size by** を選ぶ。
4. **Apply settings** を選択して図を更新する。
5. 軸範囲、マーカーの見た目、図のレイアウトを調整する。
6. 描画行を確認し、必要に応じて PNG 図をダウンロードする。

## 主な設定

- **X axis**
- **Y axis**
- **Color by / Colormap / Color range**
- **Size by / Base marker size / Size contrast**
- **Marker transparency**
- **Show background data**
- **Show legend**
- **Regression line** — 有効な X 値が 2 点以上あり、かつ値が異なる場合に、単純最小二乗回帰線、
  回帰式、相関係数、件数を表示します。
- **Axis ranges**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**
- **Uploaded data quality check** — 現在の品質フラグ条件に該当するアップロード行を表示します。

## 出力

- 任意パラメーターの2D散布図
- 任意のカラーバー・サイズ表現
- 任意の単純最小二乗回帰線
- ダウンロード可能な PNG 図
- 展開表示できるフィルタ後・アップロード済み描画データ表

## 注意点

- このページは探索用の機能です。たとえば dD と δ18O の関係を水深で色分けして
  確認できますが、科学的モデルを確立する機能ではありません。
- 描画には、選択した X 軸・Y 軸の数値が有効な行が必要です。サイズをパラメーターで変える場合は、
  その値も有効である必要があります。除外行数は設定欄の下に表示されます。
- 回帰線は視覚的な要約です。データソース間の違い、不確かさ、自己相関、科学的な外れ値を
  自動処理するものではありません。
- ブラウザからのアップロードは、現在のブラウザセッション内だけで使用されます。参照データや
  永続的な **User Excel data** を変更するものではありません。
