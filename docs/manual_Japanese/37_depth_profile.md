# 深度プロファイル

## このページでできること

δ18O、δD、d-excess、水温、塩分のいずれかを水深に対して表示し、鉛直分布を確認します。
フィルタ後の参照データと、ブラウザから任意にアップロードしたデータを重ねて表示できます。

## 基本操作

1. 参照データと **Profile parameter** を選択する。
2. 必要に応じて CSV、XLSX、または XLS をアップロードする。プロファイルには選択した
   パラメーターと `Depth_m` が必要で、地図には座標があると便利です。
3. サイドバーで条件を設定し、**Apply settings** を選択して表示を更新する。
4. 未フィルタの背景データを表示するか選ぶ。
5. 水深範囲、横軸範囲、図サイズ、フォント、目盛数を調整する。
6. プロファイルと採水地点図を確認し、必要に応じて PNG 図をダウンロードする。

## 主な設定

- **Show background data**
- **Profile parameter**
- **Depth range**
- **Axis scale**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**
- **Map controls / Map style**
- **Show uploaded data without Month information** — 月情報が有効でないアップロード行を
  プロファイルに表示するかを設定します。
- **Uploaded data quality check** — 現在の品質フラグ条件に該当するアップロード行を表示します。

## 出力

- 深度プロファイル
- 有効な経度・緯度がある場合の採水地点図
- ダウンロード可能な PNG 図
- 現在の表示に使用したフィルタ後データを展開表示

## 注意点

- 選択したパラメーターと深度の両方が有効な数値である必要があります。dD と d-excess は
  欠損値が多い場合があり、除外行数が表示されます。
- 関係のない地点・日付グループを線でつながないように、gap row を挿入しています。
- アップロードしたプロファイルは、座標がある場合に丸めた座標ごとにグループ化します。Month が
  ある場合は 1–3、4–6、7–9、10–12 月の 4 区分で色分けします。有効な Month がない行は、
  **Show uploaded data without Month information** が有効なときに、選択したアップロード用の
  スタイルで表示します。
- ブラウザからのアップロードは、現在のブラウザセッション内だけで使用されます。参照データや
  永続的な **User Excel data** を変更するものではありません。
- ダウンロード図では、長いフィルタ条件タイトルを折り返して表示します。
