# Depth Profile

## このページでできること

選択した海水パラメーターを水深に対して表示し、鉛直分布を確認します。

## 基本操作

1. データセットを選択する。
2. Profile parameter を選ぶ。
3. 背景データを表示するか選ぶ。
4. Data filtering を適用する。
5. 水深範囲、軸範囲、図サイズ、フォント、目盛数を調整する。
6. 必要に応じて図をダウンロードする。

## 主な設定

- **Show background data**
- **Profile parameter**
- **Depth range**
- **Axis scale**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**
- **Map controls / Map style**

## 出力

- 深度プロファイル
- Sampling Location Map
- ダウンロード可能な PNG 図
- フィルタ後データ表

## 注意点

- dD と d-excess は欠損値が多い場合があります。
- 関係のない観測グループを線でつながないように、gap row を挿入しています。
- ダウンロード図では、長いフィルタ条件タイトルを折り返して表示します。
