# Interactive 3D/4D Visualizer

## このページでできること

選択した参照データを、3軸に色分けの第4変数を加えた3D/4D散布図として表示します。水文関係図と地図–深度表示を確認できます。

## 基本操作

1. 参照データソースを選び、サイドバーで絞り込み条件を設定します。
2. 条件を変更した後に**Apply settings**を選びます。
3. 標準の**4D view**から1つ、または**Custom 4D view beta**を選びます。
4. 地図–深度表示では、必要に応じて地図中心、海域プリセット、深度範囲、マーカーサイズを調整します。
5. カラーマップを選び、選択した変数のカラーバー範囲を調整します。
6. 3D/4D図と連動する採水地点マップを確認します。
7. ページに操作がある場合は、インタラクティブHTMLまたは現在の表示データCSVをダウンロードします。

## 標準表示

- 塩分–δ¹⁸O–深度を水温で色分け（Fig. 1）
- 塩分–水温–深度をδ¹⁸Oで色分け（Fig. 2）
- 地図–深度をδ¹⁸O、水温、塩分、d-excessで色分け（Fig. 3–6）

**Custom 4D view beta**では、塩分–δ¹⁸O、水温–塩分、地図–深度、X–Y–Z–色の完全カスタム表示を選べます。完全カスタム表示では、異なるX、Y、Z変数と4つ以上の数値列が必要です。

## 主な設定

- **4D view**
- **Custom view type**
- **Map center for map-depth views**
- **Map-depth region preset**
- **Colormap**
- **Colorbar range**
- **Map controls / Map style**

## 出力

- 6種類の標準4D表示
- Custom 4D view beta
- Sampling Location Map
- 選択した図と採水地点マップの自己完結型インタラクティブHTML
- 現在の表示データ表とCSV出力

## 注意点

- 全球データなど大きな選択では重くなることがあります。
- map-depth 表示では、地理的な縦横比と海岸線を反映します。
- Custom 4D view beta は試験的機能です。
- このページではブラウザからのアップロードには対応していません。常時読み込みの**User Excel data**は、アプリ起動前にrepository外のパスから指定できます。詳しくは[データの絞り込み](01_data_filtering.md)を参照してください。
