# Interactive 3D/4D Visualizer

## このページでできること

海水データを 3D/4D 散布図として表示し、地図的な位置、水深、色分け変数を同時に確認できます。

## 基本操作

1. データセットを選択する。
2. Data filtering を適用する。
3. 4D view を選ぶ。
4. map-depth region や図設定を調整する。
5. Colorbar range を調整する。
6. 4D図と採水地点マップを確認する。

## 主な設定

- **4D view**
- **Custom view type**
- **Map center for map-depth views**
- **Map-depth region preset**
- **Colormap**
- **Colorbar range**
- **Map controls / Map style**

## 出力

- 標準 Fig.1-Fig.6 型の 4D 表示
- Custom 4D view beta
- Sampling Location Map
- 選択データ表

## 注意点

- 全球データなど大きな選択では重くなることがあります。
- map-depth 表示では、地理的な縦横比と海岸線を反映します。
- Custom 4D view beta は試験的機能です。
