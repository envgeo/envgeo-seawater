# 水温–塩分図

## このページでできること

フィルタ後の参照データと、ブラウザから任意にアップロードしたデータの水温–塩分
（T–S）関係を表示します。近似 σ0 参照等値線を重ね、座標が有効な場合には採水地点図も表示します。

## 基本操作

1. 参照データを選択し、サイドバーで条件を設定する。
2. 必要に応じて CSV、XLSX、または XLS をアップロードし、水温・塩分列を割り当てる。
   採水地点図には経度・緯度列も必要です。
3. **Show background data**、色分け項目、その他の表示設定を選ぶ。
4. **Apply settings** を選択して図を更新する。
5. 軸、カラーバー、σ0 参照等値線の間隔を必要に応じて調整する。
6. 描画データを確認し、必要に応じて PNG 図をダウンロードする。

## 主な設定

- **Show background data**
- **Show legend**
- **Color parameter**
- **Colorbar range**
- **Salinity scale**
- **Temperature scale**
- **Density contour interval (approx. σ0)** — 近似 σ0 参照等値線の間隔
  （0.2、0.5、1.0 kg m⁻³ から選択；既定値 0.5 kg m⁻³）
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**
- **Map controls / Map style**
- **Uploaded data quality** — 現在のブラウザアップロードについて、利用可能な行数と
  必須値の欠損を表示します。

## 出力

- 水温–塩分（T–S）図
- 密度等値線
- 有効な経度・緯度がある場合の採水地点図
- ダウンロード可能な PNG 図
- フィルタ後データ表

## 注意点

- 密度等値線の描画には、有効な水温・塩分値が必要です。
- 欠損値を含む点は図から除外され、caption に件数が表示されます。
- ブラウザからのアップロードは、現在のブラウザセッション内だけで使用されます。
  参照データや永続的な **User Excel data** を変更するものではありません。
- 密度等値線は**近似的な σ0 参照格子**であり、個々の観測値の密度ではありません。
  実用塩分（≈ 絶対塩分）と現場水温（≈ 保存温度）を、そのまま `gsw.sigma0` に渡しており、
  各観測値の位置・圧力を用いた絶対塩分・保存温度への変換は行っていません。
  厳密に変換したTEOS-10値との差は、データセット、地点、深度、水塊・海況によって変わります。
  等値線は視覚的な参照用途に限定し、真の TEOS-10 密度値や定量的な水塊分類の根拠には
  使用しないでください。
- 等値線格子は選択された表示軸範囲を基礎とし、品質チェック済みの入力許容範囲
  （塩分 0–50；水温 −5–45 °C）にクリップします。軸設定で負の塩分が選択されても、
  密度計算には渡されません。
