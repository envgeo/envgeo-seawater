# Salinity-d18O Relationship

## このページでできること

塩分と d18O の関係を散布図として表示します。

## 基本操作

1. データセットを選択する。
2. 背景データを表示するか選ぶ。
3. 回帰線を表示するか選ぶ。
4. Data filtering を適用する。
5. 図の見た目を調整する。
6. 必要に応じて図をダウンロードする。

## 主な設定

- **Show background data**
- **Regression line**
- **Color parameter**
- **Salinity scale**
- **d18O scale**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**
- **Map controls / Map style**

## 出力

- 塩分-d18O 散布図
- 任意の回帰線
- Sampling Location Map
- ダウンロード可能な PNG 図
- フィルタ後データ表

## 注意点

- 回帰線は探索的な解釈の補助です。
- 塩分、d18O、色分けパラメーターに欠損がある点は図から除外されます。
