# 塩分–δ¹⁸O関係図

## このページでできること

絞り込んだ参照データと、必要に応じてブラウザからアップロードしたデータについて、塩分とδ¹⁸Oの関係を散布図として表示します。

## 基本操作

1. 参照データソースを選び、サイドバーで絞り込み条件を設定します。
2. 必要に応じて**Uploaded data overlay**からセッション限定データをアップロードします。関係図には塩分とd18Oの列割当が必要です。アップロード地点を地図に表示するには、有効な経度・緯度も必要です。
3. 背景データと回帰線を表示するか選びます。
4. 条件を変更した後に**Apply settings**を選びます。
5. 色、色範囲、軸範囲、図サイズ、目盛りラベルを調整します。
6. アップロードしたデータがある場合は、品質確認を確認します。
7. ページに操作がある場合は、PNG図または抽出データ表をダウンロードします。

## 主な設定

- **Show background data**
- **Regression line**
- **Color parameter**
- **Salinity scale**
- **d18O scale**
- **Figure width / height**
- **Tick font size / Label font size**
- **X tick count / Y tick count**
- **Map controls / Map style**

## 出力

- 塩分–δ¹⁸O散布図
- 任意の回帰線
- Sampling Location Map
- ダウンロード可能な PNG 図
- フィルタ後データ表
- アップロードデータの品質確認と重ね描き（使用時）

## 注意点

- 回帰線は探索的な解釈の補助です。
- 回帰には、有効な塩分–d18Oの点が少なくとも2点必要です。条件を満たさない場合は回帰線を表示しません。
- 塩分またはd18Oが欠損した点は関係図から除外されます。選んだ色分けパラメーターが欠損した点は、アップロードマーカーの代替スタイルで表示することを選べます。
- ブラウザからのアップロードは現在のStreamlitセッション内だけで扱い、参照データや常時読み込みの**User Excel data**を変更しません。
