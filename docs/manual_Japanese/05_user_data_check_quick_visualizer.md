# User Data Check & Quick Visualizer

## 目的

CSV/XLSXをアップロードしてから専門的な図を作る前の、公開されたデータ確認・簡易可視化の入口です。メモリ内限定のアップロード、変更可能な列認識、品質・欠損確認、共通Data filtering、簡易2D--4D可視化をまとめています。

## 基本操作

1. サイドバーからCSVまたはXLSXをアップロードします。
2. 自動認識された列を確認し、必要なら対応を修正します。
3. アップロードだけを見る場合は **Comparison data source** を `None` のままにし、比較する場合だけ参照データを選びます。
4. Data filteringで`Uploaded data`、参照データ、または両方を選び、**Apply settings** を押します。
5. Overview & Qualityで品質・欠損を確認し、各図・地図タブを使います。
6. 必要に応じてフィルター後のCSVをダウンロードします。

## タブ

- **Overview & Quality**: 件数、値の利用可否、品質フラグ、アップロードプレビュー
- **2D Explore**: 任意X-Y、Salinity-d18O、Temperature-Salinity
- **3D / 4D**: X、Y、Z、色（第4変数）を選ぶ散布図
- **2D Map**／**3D Map**: パレット、海域、視点を設定する地理的確認
- **Data & Export**: フィルター後の表とCSV出力

## 性能とデータの扱い

Plotly図の初期 **Maximum plotted rows** は、操作性のため5,000件です。上限が効いている場合は、何件中何件を描画しているかを画面に表示します。ブラウザとデータ量に余裕がある場合は最大50,000件まで増やせます。アップロードファイルと参照＋アップロードの一時データは、現在のStreamlitセッション中のメモリだけで扱い、アプリは保存しません。
