# User Data Check & Quick Visualizer

## 目的

CSV、XLSX、XLSをアップロードしてから専門的な図を作る前の、公開されたデータ確認・簡易可視化の入口です。メモリ内限定のアップロード、変更可能な座標列の割当、品質・欠損確認、共通Data filtering、簡易2D--4D可視化をまとめています。

## 基本操作

1. サイドバーの**Uploaded data overlay**からCSV、XLSX、XLSをアップロードします。ファイルを読み込む前には、CSVテンプレートをダウンロードできます。
2. 自動認識された列を確認します。数値列は2D/3Dの軸に使えます。地図または地理3D表示には、**Uploaded data columns**で経度・緯度・深度の列を割り当てます。
3. アップロードだけを見る場合は **Comparison data source** を `None` のままにし、比較する場合だけ参照データを選びます。
4. Data filteringで`Uploaded data`、参照データ、または両方を選び、**Apply settings** を押します。
5. Overview & Qualityで品質・欠損を確認し、各図・地図タブを使います。
6. ページに操作がある場合は、フィルター後のCSVまたはインタラクティブ図をダウンロードします。

## 3D図の視点操作

**3D / 4D**と**3D Map**タブでは、メインの3D/4Dページと同じ操作を使えます。図内をドラッグして視点を回転し、右上のPlotlyツールバーで回転・平行移動・拡大縮小を切り替え、初期視点へ戻せます。**Shift**、**Control**、**Command**を押しながらの操作ではドラッグ時の挙動が変わることがありますが、実際の挙動はブラウザとOSにより異なります。

## アップロードデータの扱い

一般的な英語列名と明確な日本語列名は自動認識します。自動認識後も列の対応は変更できます。標準化後も数値として解釈できない値は欠損値として扱い、品質確認に表示します。アプリ内部のメタデータ列は、プレビュー、ダウンロード、軸の候補には表示しません。

アップロード欄の**Clear shared uploaded data**を選ぶと、現在のブラウザセッションで共有しているアップロードデータを消去できます。ローカルファイルや同梱参照データセットは変更しません。

## タブ

- **Overview & Quality**: 件数、値の利用可否、品質フラグ、アップロードプレビュー
- **2D Explore**: 任意X-Y、Salinity-d18O、Temperature-Salinity
- **3D / 4D**: X、Y、Z、色（第4変数）を選ぶ散布図
- **2D Map**／**3D Map**: パレット、海域、視点を設定する地理的確認。地理3D表示には経度・緯度・深度の列割当が必要です。
- **Data & Export**: フィルター後の表とCSV出力

## 性能とデータの扱い

Plotly図の初期 **Maximum plotted rows** は、操作性のため5,000件です。上限が効いている場合は、何件中何件を描画しているかを画面に表示します。ブラウザとデータ量に余裕がある場合は最大50,000件まで増やせます。アップロードファイルと参照＋アップロードの一時データは、現在のStreamlitセッション中のメモリだけで扱い、アプリは保存しません。アップロードによって、同梱参照データセットや常時読み込みの**User Excel data**が変更されることはありません。
