# Isotope & Hydrographic Mapping

## このページでできること

d18O、dD、d-excess、塩分、水温などの同位体・海洋環境パラメーターを地図上に表示します。

## 基本操作

1. データセットを選択する。
2. Data filtering を適用する。
3. 地図に表示するパラメーターを選ぶ。
4. Map type を選ぶ。
5. Map display settings を調整する。
6. 必要に応じて地図をダウンロードする。

## 主な設定

- **Mapped parameter**
- **Map type**
- **Map center**
- **Colormap**
- **Map longitude / latitude range**
- **Colorbar range**
- **Colorbar thickness / length / font size**
- **Map controls / Map style**

## 出力

- Scatter map
- Contour-style map
- Sampling Location Map
- ダウンロード可能な地図画像
- フィルタ後データ表

## 注意点

- Contour-style map は、データ密度と補間方法の影響を受けます。
- Map display settings は Data filtering とは別の表示範囲設定です。
